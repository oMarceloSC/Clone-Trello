# Roadmap

## Visão Geral

Este documento apresenta o planejamento de desenvolvimento do Clone do Trello.

O projeto será desenvolvido por milestones, permitindo evolução contínua da aplicação mantendo estabilidade e organização da base de código.

---

## Infraestrutura

- [x] Configuração do projeto
- [x] Docker
- [x] PostgreSQL
- [x] Prisma ORM
- [x] Sistema de Migrations
- [x] Fastify
- [x] TypeScript

## Arquitetura

- [x] Estrutura modular
- [x] Controllers
- [x] Use Cases
- [x] Schemas
- [x] Middlewares
- [x] Tratamento global de erros
- [x] Validação de ambiente

## Autenticação

- [x] Cadastro
- [x] Login
- [x] JWT
- [x] Hash de senha
- [x] Middleware de autenticação
- [x] Endpoint `/auth/me`
